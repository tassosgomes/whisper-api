## Pré-requisitos

- No PowerShell, na raiz do repositório: `dotnet run --project clients/windows-recorder/src/Host`.
- Um editor de texto para colar (Bloco de Notas) e uma pasta de teste para exportar, por exemplo `C:\Temp\whisper-v08`.
  Crie-a antes: `New-Item -ItemType Directory C:\Temp\whisper-v08`.
- Uma gravação **transcrita**. Há dois caminhos; marque o usado: [ ] A (API publicada) [ ] B (arquivos locais)

### Caminho A: com a API publicada

Grave cerca de 1 minuto de fala, envie com **Transcrever** e espere a situação "Transcrita" (como na 12.0).

### Caminho B: preparar uma gravação "transcrita" a partir de arquivos locais (sem a API)

1. Grave 5 a 10 segundos (falando algo), pare e salve. **Feche o app** (janela ou "Sair" na bandeja).
2. Abra a pasta das gravações e entre na pasta mais recente (a que tem `audio.wav`):
   `explorer "$env:LOCALAPPDATA\Whisper\Recorder\recordings"`. Pasta usada: ____________________
3. Em `metadata.json`, troque `"state": "saved"` por `"state": "transcribed"` (nada mais). Salve em UTF-8.
4. Na mesma pasta crie `result-v1.json` (UTF-8):

   ```json
   {
     "schemaVersion": 1,
     "segments": [
       { "startMs": 1240, "endMs": 4000, "text": "Olá, esta é a primeira frase da reunião." },
       { "startMs": 5300, "endMs": 9000, "text": "Aqui vai um segundo trecho, com acentuação: ação, coração." },
       { "startMs": 3661007, "endMs": 3665000, "text": "Um trecho tardio, depois de mais de uma hora." }
     ]
   }
   ```

5. Na mesma pasta crie `transcription.txt` (UTF-8), uma linha por trecho, exatamente neste formato:

   ```text
   [00:00:01.240] Olá, esta é a primeira frase da reunião.
   [00:00:05.300] Aqui vai um segundo trecho, com acentuação: ação, coração.
   [01:01:01.007] Um trecho tardio, depois de mais de uma hora.
   ```

6. Para o teste de **transcrição vazia** (item 5), repita os passos com outra gravação, com
   `"segments": []` no `result-v1.json` e `transcription.txt` vazio.
7. Abra o app. Esperado: a(s) gravação(ões) aparecem com a situação "Transcrita". Resultado: ____________________

2. Selecione a gravação transcrita na lista.
   - Esperado: o botão **Abrir transcrição** fica ativo (em gravações que não estão "Transcrita" ele fica inativo).

     Nenhum erro de rede nem pedido de configuração. Acentos corretos.
   - Resultado: ____________________
4. Durante a abertura, a janela principal continua respondendo (sem travar). Resultado: ____________________

## 2. Copiar com e sem tempos e colar em outro programa

1. Clique em **Copiar com tempos** (ou Ctrl+C). Esperado: a frase "Transcrição copiada com os tempos.".
2. Cole no Bloco de Notas (Ctrl+V).
   - Esperado: uma linha por trecho, começando com `[HH:mm:ss.fff]`, igual ao `transcription.txt`.
   - Resultado: ____________________
3. Limpe o Bloco de Notas, volte à janela e clique em **Copiar sem tempos** (ou Ctrl+Shift+C). Esperado: "Transcrição copiada sem os tempos.".
4. Cole no Bloco de Notas. Esperado: só os textos, uma linha por trecho, sem os colchetes de tempo.
   - Resultado: ____________________
5. (Opcional) Abra o Win+V e confira que o histórico mostra a última cópia. Resultado: ____________________
6. (Opcional, área de transferência ocupada) Se tiver um programa que segura a área de transferência (por exemplo uma
   ferramenta de gerenciamento remoto), copie de novo: o app tenta de novo por um instante e, se não conseguir, mostra
   "Não foi possível copiar: outro programa está usando a área de transferência. Tente de novo." sem travar nem fechar.
   Resultado (ou "não testado"): ____________________

## 3. Exportar e sobrescrever com confirmação

1. Clique em **Exportar…** (ou Ctrl+S). Esperado: o seletor de arquivo do Windows, com nome sugerido
   `<título> - transcrição.txt` e filtro `.txt`. Nome sugerido: ____________________
2. Escolha `C:\Temp\whisper-v08\reuniao.txt` e salve.
   - Esperado: "Transcrição exportada para reuniao.txt.". O arquivo abre no Bloco de Notas com os tempos e os acentos corretos.
   - Resultado: ____________________
3. Exporte de novo para o **mesmo** nome (`reuniao.txt`).
   - Esperado: o seletor **não** pergunta nada sobre sobrescrever; em seguida o app mostra uma única caixa
     "Substituir o arquivo?" com **Substituir** e **Cancelar**.
   - Resultado: ____________________
4. Clique em **Cancelar**. Esperado: "Exportação cancelada. O arquivo existente foi mantido."; o arquivo continua
   igual (confira o conteúdo e a hora de modificação). Resultado: ____________________
5. Edite `reuniao.txt` no Bloco de Notas (acrescente uma linha "teste"), salve e feche. Exporte de novo, escolha o mesmo
   arquivo e clique em **Substituir**.
   - Esperado: "Transcrição exportada para reuniao.txt."; a linha "teste" sumiu.
   - Resultado: ____________________
6. Em **Exportar…**, clique em **Cancelar** no seletor. Esperado: "Exportação cancelada."; nenhum arquivo novo. Resultado: ____________________
7. (Opcional) Exporte para uma pasta sem permissão de escrita, por exemplo `C:\Windows`. Esperado: mensagem
