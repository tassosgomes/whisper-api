# Resumo da task 8.0 — acesso à API no host Windows

Sessão Windows 11 (implementação por subagent Sonnet, validação independente por subagent Haiku,
revisão e integração pelo coordenador). Gate: passed. Validação manual: aprovada
(`8.0_manual_validation.md`, API `https://whisper.lab.tasso.dev.br/v1`). Revisão em `8.0_task_review.md`.

## Entrega

Todos os caminhos são relativos a `clients/windows-recorder/`.

- `src/Host/Access/WindowsCredentialVault.cs`: `ICredentialVault` sobre o Windows Credential Manager
  (`CredWriteW`/`CredReadW`/`CredDeleteW`, credencial genérica, usuário `api-key`). Alvo do app
  `Whisper.Recorder/ApiKey`; testes em `Whisper.Recorder.Test/...` com GUID. Persistência
  `LOCAL_MACHINE`: sobrevive ao reinício, restrita ao usuário, sem roaming. Bytes UTF-8 e buffer
  não gerenciado zerados após o uso; `CredFree` sempre; erros só com o código do Windows.
- `src/Host/Access/ApiAccessWindow.xaml(.cs)`: configurações em WPF-UI com endereço, API Key em
  campo de senha sem binding (lido no clique e limpo antes do primeiro `await`), mensagem de
  validação em linguagem simples, chave mascarada com os 4 últimos caracteres, substituir e remover.
- `src/Host/App.xaml.cs`, `MainWindow.xaml(.cs)`: composição do cofre, do serviço e do ViewModel;
  botão "Configurações". O app grava sem configuração; o ponto de entrada do envio (10.0) é
  `ApiAccessViewModel.RequestSendAsync()`, que dispara `ConfigurationRequested` → `ShowSettings()`.
- Testes: `tests/Host.Tests/V05CredentialVaultTests.cs` e `V05ApiAccessScreenTests.cs` (cofre real
  com alvo de teste e limpeza no `Dispose`; nova instância lê o que a anterior gravou; chave ausente
  dos arquivos do app e do diário; integração tela/ViewModel com API simulada em memória).
- Docs: `README.md` (seção do acesso à API no host).

Core e Presentation não foram alterados nesta task.

## Limitações preservadas

A chave transita como `string` imutável no núcleo (`ICredentialVault`, `ApiAccessService`,
`ApiAccessViewModel`) e não pode ser zerada; mudar exigiria alterar as assinaturas do núcleo.
O endereço aceita `http://`; a chave pode trafegar sem TLS se o usuário configurar assim (regra do núcleo, 7.0).
